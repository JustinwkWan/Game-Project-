# Physics Game

A Unity game that uses physics simulation to move and interact with objects.

## What It Does

An experimental game built in Unity exploring physics-based object movement and interaction. Objects respond to forces, collisions, and gravity through Unity's built-in physics engine.

## Tech Stack

- **Engine:** Unity
- **Language:** C#

## Getting Started

1. Install [Unity Hub](https://unity.com/download)
2. Open this project folder in Unity Editor
3. Press **Play** in the editor to run the game
